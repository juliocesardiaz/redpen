    Import from GitHub

    Paste a GitHub file URL (the "blob" link from the file view) or a raw.githubusercontent.com URL.

    Fetches each student's submit50 submission: github.com/<org>/<username>, branch = slug. The likeliest source file is picked automatically and shown after import.

    Use the JSON export downloaded from submit.cs50.io. Each submission is fetched at its exact submitted commit, real names are used when present, and check50 results prefill the score.

    The token is used only for this fetch and is never saved or exported. CS50 modes need a classic token (ghp_…) with the repo scope — fine-grained tokens can't access me50 org repos.
